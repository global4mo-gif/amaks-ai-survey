# Онлайн-сбор ответов в Google Sheets и Excel

GitHub Pages показывает статичный сайт, поэтому сам по себе он не может записывать ответы в общий Excel-файл. Для общего онлайн-сбора используется Google Таблица и маленький Google Apps Script.

Созданная таблица для ответов:

https://docs.google.com/spreadsheets/d/1bxfMaZk7o_eKWKcaBwvXx7V9DdDJaAC_cJ23t4_zhj8/edit

## Настройка

1. Откройте Google Таблицу по ссылке выше.
2. В меню выберите `Расширения -> Apps Script`.
3. Удалите код по умолчанию и вставьте содержимое файла `apps-script/Code.gs`.
4. Нажмите `Сохранить`.
5. Нажмите `Развернуть -> Новое развертывание`.
6. Тип выберите `Веб-приложение`.
7. `Выполнять от имени`: `Я`.
8. `У кого есть доступ`: `Все`.
9. Нажмите `Развернуть`, разрешите доступ и скопируйте URL веб-приложения.
10. В файле `script.js` замените:

```js
const GOOGLE_SCRIPT_URL = "";
```

на:

```js
const GOOGLE_SCRIPT_URL = "ВАШ_URL_ВЕБ_ПРИЛОЖЕНИЯ";
```

11. Закоммитьте и запушьте изменение в GitHub.

После этого онлайн-страница будет отправлять ответы в Google Таблицу. Excel скачивается из Google Sheets: `Файл -> Скачать -> Microsoft Excel (.xlsx)`.
